# ChordPro Songbook Builder

Turns a folder of [ChordPro](https://www.chordpro.org/) song charts and Markdown setlists
into a standalone, interactive, printable songbook — a single HTML file with a song list,
transposition, chord diagrams, setlists, and a print mode. No server, no install, no account.

- [**Build your own songbook**](build/) — pick a folder of `.cho`/`.pro`/setlist files.
- [**See a sample songbook**](demo/songbook.html) — built from the files in [`demo/`](demo/).
- [The ChordPro dialect this uses](chordpro-format.html) — where it came from.
- [Source on GitHub](https://github.com/ptsefton/c2c-chordpro-plugin)
